# MIT Indoor67 Scene Classification

Duke Applied Machine Learning AI Training Program — Fall 2026

## Objective
Classify indoor scene images into 67 categories using machine learning.

## Approaches
- Classical image features
- Convolutional neural networks
- Transfer learning

## Project Structure
- `data/`: Dataset instructions
- `notebooks/`: Exploration and experiments
- `src/`: Training and inference code
- `experiments/`: Results and comparisons
- `checkpoints/`: Model weights
- `submissions/`: Kaggle submissions

## Getting Started
Install dependencies:

```bash
pip install -r requirements.txt
```
